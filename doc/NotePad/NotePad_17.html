5 Known Bugs

The following bugs are known to exist in version 1.7.2 (build date 2026.06.11) of Note Pad. If you encounter any other bugs, please go to my project page on GitHub to report them:

https://github.com/Typraeurion/Android-NotePad/issues

  • Under certain conditions in particular on Android 9+, selecting a different category on the note list page may not update the note list. This is an intermittent issue that was introduced as part of the refactoring done in version 1.5 and should not affect older versions. Until a fix can be confirmed, the workaround is to restart the app.
  • When unlocking or locking encrypted records, the list of notes may not be properly updated right away especially on older devices. Encrypted entries should update their display when the list is scrolled or rotated.

The following bugs were in the 1.7.1 release (built 2026.05.10) but have been fixed as of 1.7.2 (built 2026.06.11).

  • The export and import activities would cause the app to crash if the user had previously exported to or imported from a file in shared storage and permission to use that file has expired (e.g. after the app has been stopped or the device reboots.) This bug was introduced in version 1.7.0 with the addition of ZIP file support and does not impact older versions.

The following bugs were in the 1.7.0 release (built 2026.04.04) but have been fixed as of 1.7.1 (built 2026.05.10).

  • When attempting to uninstall the app on an Android 10 (Quince Tart), 11 (Red Velvet Cake), or possibly 12 (Snow Cone) device, Android’s package installer would crash in attempting to determine if the app had any data the user may wish to keep. This bug was introduced in version 1.4 (when targeting Android 12) so did not affect versions 1.3.2 and earlier.

The following bugs were in the 1.6.0 release (built 2026.03.18) but have been fixed as of 1.7.0 (built 2026.04.04).

  • When running on Android 6 (Marshmallow) or earlier, there’s a bug in the export service where if you try to back up the data to a new file it will fail. This bug was introduced with changes made in version 1.5 and does not affect older versions.
  • When attempting to import a backup file in “Clean” mode, nothing gets imported even though the operation completes normally. This is a regression bug that was introduced in version 1.5 and does not affect older versions.
  • With the scroll bar enabled, when text is added to or removed from a note the relative size of the scroll thumb changes as it should but the thumb’s position was not properly set.

The following bugs were in the 1.5.1 release (built 2025.12.28) but have been fixed as of 1.6.0 (built 2026.03.18).

  • When opening NotePad, the category list may reset to “All” instead of staying on the category that was selected the last time the app was used.
  • When the editor is restarted due to a configuration change (e.g. rotating the screen, attaching or detaching an external keyboard) any changes made to your note will be lost.
  • The amount of notes that can be imported from a previously exported file is limited by the amount of memory available to the application. If you find that the application dies when importing a file, try splitting the file into two or more smaller files, copying the ‘<Metadata>’ and ‘<Categories>’ sections into each file, and import them separately.
  • When importing a backup file, the progress bar may not update properly.

The following bugs were in the 1.5.0 release (built 2025.12.27) but have been fixed as of 1.5.1 (built 2025.12.28).

  • If “Show private records” is set in the Settings but a password has not been entered, encrypted records are not shown.

The following bugs were in the 1.4.0 release (built 2025.03.27) but have been fixed as of 1.5.0 (built 2025.12.27).

  • It is not possible to delete the last remaining category in the category list.

The following bugs were in the 1.3.0 release (built 2015.05.10) but have been fixed as of 1.3.1 (built 2025.03.16).

  • If you press the back button while editing a note, all changes are discarded without warning.
