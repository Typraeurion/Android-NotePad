4.3 Exporting a Single Note

On Android 7 (Nougat) and newer versions, you can save individual notes as plain text files. Open the note and click on the “Details…” button, then click “Export Note…”. Choose the folder where you want to save the file and enter a file name. (By convention, text files should end in “.txt”.) Then click “Save”.

If you try to export a private note which is encrypted, NotePad will warn you that the text file it is about to write will not be encrypted. You have the option to cancel the export at this time.

The app will show a brief message indicating that the file was written once it has finished.
