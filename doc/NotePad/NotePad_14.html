4.2.1 Importing from a ZIP File

You can import notes from a ZIP file whether it was created by this app or another program. If the ZIP file was created by Note Pad, the import will work the same as importing a Note Pad XML file.

If your ZIP file was created by some other application, text files from the ZIP will be added as new notes regardless of the import type chosen. Files in the root folder will be placed in the “Unfiled” category, while those in a top-level folder will be assigned a category named as that folder. Files must contain only plain text encoded in ASCII or UTF-8; otherwise they will be skipped. (Files written with ISO-8859-*, Windows-125*, or other encodings are not accepted unless they contain only basic ASCII characters.)
